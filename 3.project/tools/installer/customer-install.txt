C-Pilot을 현재 Windows 사용자 계정에 설치합니다.

Python 실행 환경과 앱 화면을 포함합니다. Python과 Node.js를 별도로 설치할 필요가 없습니다.
처음 실행하면 빈 업무함과 담당자·대표 초기 계정 안내가 생성됩니다.
기존 고객 업무 자료·계정·비밀번호는 설치 파일에 포함하지 않습니다.

로컬 AI는 선택 항목입니다. 처음 준비할 때 Ollama와 Qwen 모델 약 12GB를 인터넷으로 다운로드합니다.
준비가 끝난 뒤 문서 분석은 로컬 모델로 실행됩니다. 실패하면 AI 사용을 완료 상태로 표시하지 않습니다.
Ollama가 이미 실행 중이면 기존 서버를 임의로 종료하지 않습니다.

업무 자료와 백업은 %LOCALAPPDATA%\C-Pilot 아래에 보관합니다.
앱 제거와 업데이트는 업무 자료·백업·Ollama 모델을 삭제하지 않습니다.
업데이트 전에는 분석·저장을 마치고 백업하세요. 설치 중 C-Pilot 서버가 종료됩니다.

Windows 10 22H2 이상 x64가 필요합니다. 스캔 OCR에는 Windows 한국어 OCR 기능이 필요합니다.
AI 속도는 GPU·메모리 사양에 따라 달라집니다.
