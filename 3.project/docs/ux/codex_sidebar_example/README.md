# Codex 사이드바 UI 예시

사용자가 ‘Codex가 만들면 어떤 느낌인지’를 요청해서 만든 독립 클릭 시안이다. Claude ERP형 W6의 요약·변경·결재·의견 이력 구조를 기반으로, 사용자 선택인 왼쪽 사이드바 토글과 더 읽기 쉬운 글자·간격을 적용했다. 원래 시안을 그대로 복제한 결과는 아니다.

- 앱 코드와 API/DB를 연결하지 않는다. frontend/, 측정 빌드, v3/test2 평가를 변경하지 않았다.
- 모든 이름·계약·금액·원문·기록은 가상 자료다. 새로 고치거나 ‘시안 초기화’를 누르면 초기 상태로 돌아간다.
- 기본 시작 화면: 대표 결재. 왼쪽 ‘업무함’에서 목록을 볼 수 있다.
- `codex-sidebar-example.html`은 JS/CSS를 넣은 독립 HTML이다. 일반 브라우저에서 열 수 있다. 스크립트를 막는 문서 미리보기에서는 클릭 기능을 사용할 수 없다.

## 실제 앱 반영 결정

2026-10-06 사용자가 팀 동의와 마스킹 범위 확인을 전달해 이 Codex 새안의 실제 앱 반영 방향을 승인했다. [구현 인계 기준](../codex_sidebar_implementation_handoff_20261006.md)에 화면별 연결·기존 마스킹 예외·작업 순서·브라우저 확인 장면을 정리했다. 이 승인과 문서 추가만으로 앱 반영이 완료된 것은 아니다. 독립 시안의 가상 데이터와 단계 이동은 그대로 유지한다.

## 눌러 볼 것

1. 대표 결재 예시에서 의견 10자 이상과 미조회 확인을 입력한다. 사이드바를 접고 펴도 입력을 유지한다. 승인/반려하면 시안 상태와 의견 이력이 바뀐다.
2. 서류/요청 내역/결재/처리 기록 탭을 전환한다.
3. 견적서 원문을 열어 금액·부가세·상호의 근거를 선택한다. 원문과 같음, 값 수정 입력 흐름을 확인한다. Tab/Shift+Tab/Esc를 지원한다.
4. 업무함의 ‘홈페이지 유지보수’에서 누락 외부 서류 2종을 한 번에 요청한다. 기한·방법·문구 복사와 외부 요청 후 기록은 별개다. 받은 서류만 체크하면 부분 회신으로 남는다.
5. 검색·상태 필터·빈 결과, 가상 계약 등록 입력을 확인한다.
6. 모바일 폭에서는 메뉴 버튼으로 사이드바를 열고 닫는다. 목록은 계약별 행으로 바뀌고, 원문 대조는 원문/읽은 값을 전환한다.

파일 입력은 선택한 이름만 사용하며 업로드·저장을 수행하지 않는다. 견적서 외 원문은 이 시안의 제공 범위에 없으므로 해당 보기 버튼은 비활성이다. 서버의 권한·동시 수정·평가·수령본 영구 연결을 구현한 것이 아니다. 결재자는 현재 2단계 예시만 제공한다.

## 로컬 개발

```text
npm install --prefer-offline --no-audit --no-fund
npm run dev -- --host 127.0.0.1 --port 8074 --strictPort
npm run build
node scripts/export-html.mjs
```

Product Design prototype 템플릿, React/Vite, 기존 앱과 같은 Lucide 아이콘을 사용했다. 사진/장식 이미지가 없는 데이터 화면이며 원문은 가상 문서의 표와 텍스트다. 시안의 상세 확인 범위와 제한은 `design-qa.md`에 기록한다.
