# C업체(소기업) 시범 프로필

이 프로필은 서비스 설계와 시연을 위한 가정이다. 실제 기업 조사·매출 확인·법적 기업 규모 판정 결과가 아니다.

| 항목 | 시범 기준 |
| --- | --- |
| 규모 | 직원 6명 |
| 업무량 | 월 약 150건의 검수 업무. 실측·부하 검증 수치가 아닌 운영 가정 |
| 앱 담당자 | 1명. 서류 등록·원문 확인·추출값 보완·재제출 연락 기록 |
| 최종 확인 | 대표가 최종 확인. 담당자의 실무 검토와 공식 결재 단계를 구분 |
| 거래처 연락 | 담당자가 카카오톡·문자·이메일로 직접 연락. 앱은 보낸 요청과 회신을 기록 |
| 회사 설정 | `SMALL_BUSINESS`, 대표 결재 1단계 |
| 필수 서류 | 기본 6종: 계약서·견적서·사업자등록증·통장사본·세금계산서·검수확인서. 회사가 설정 |

## 시범 업무 흐름

담당자 등록 → 규칙 추출과 필요한 칸의 로컬 LLM 보완 → 원문·근거 확인 → 필요한 경우 거래처에 직접 보완 요청 → 요청·기한 기록 → 회신과 재제출 확인 → 대표 최종 확인.

문제가 남은 값은 원문을 보고 확인한다. AI의 채택 여부와 대표의 최종 확인은 별개이며 가드 통과만으로 사람 확인이 끝난 것으로 기록하지 않는다. 대표가 검토한 자료가 바뀌면 다시 확인한다. 국세청 미연동 상태를 정상 사업자 확인으로 표시하지 않는다.

## 중견 확장과 구분

| 구분 | 시범 C업체 | 확장 설계 |
| --- | --- | --- |
| 프리셋 | `SMALL_BUSINESS` | `MID_SIZED` |
| 공식 결재 | 대표 1단계 | 담당 검토 → 대표, 최대 2단계 |
| 검토자 | 담당자 실무 확인 후 대표 결재 | 단계마다 다른 사람, 자료 변경·반려 후 다시 검토 |
| 확인 범위 | 위 소규모 업무 흐름의 시범 | 중견 규모 운영·동시 사용·부하·조직 권한은 추가 검증 필요 |

백엔드의 2단계 결재 구조는 마련했지만 C업체에 2단계 설정을 적용한 것은 아니다. 중견 운영의 효과나 법적 규모 적합성을 이번 시범 결과로 주장하지 않는다.

## 기업 규모 표현

**소기업/소상공인 구분은 업종별 매출 기준이 있어 확인 필요**하다. 소상공인 여부에는 업종별 상시 근로자 요건도 관련되므로 직원 6명이라는 가정만으로 판정하지 않는다. 법적 기준 확인은 [중소기업기본법 시행령 제8조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1031550509)와 [소상공인기본법 제2조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0002&lsiSeq=280155&urlMode=lsScJoRltInfoR)를 참고한다.

앱의 `SMALL_BUSINESS`·`MID_SIZED`는 회사가 선택하는 업무 설정 이름이며 법적 기업 규모 판정 기능이 아니다.
