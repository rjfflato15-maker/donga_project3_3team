# 배포·판매 검토 범위

> 상태: 현재 기준
> 확인일: 2026-10-07
> 기준: 현재 소스 전용 배포와 이전 설치 기록. 판매 검토 완료 문서가 아님.

현재 배포는 소스 전용이다. 이전 버전의 Setup 빌드·격리 설치·업데이트·제거 기록은 현재 소스의 설치 검증을 대신하지 않는다. 이번 작업은 EXE 재빌드를 포함하지 않으며 Windows 실행·새 PC·실제 AI 준비·설치 마법사 시각 검사는 별도 확인 대상이다. 진행 상태는 [고객 설치 안내](customer_package.md)가 기준이다.

고객에게 제공할 앱·자료·소스·모델·문서 범위를 [배포 경계](../development/distribution_boundary.md)에서 정한다. EXE 입구나 Python 런타임 포장이 코드 비공개·복제 차단을 보장하지 않는다. 제출용 공개 자료와 고객용 제품·지원 범위는 별도로 정해야 한다.

라이브러리 고지와 모델 조건을 확인한다. 현재 requirements의 pyhwp 0.1b15는 AGPLv3+로 확인되어 판매 배포 전에 대응 소스 제공 등 적용 범위를 검토해야 한다. Qwen 모델의 상업 이용 가능성만으로 앱 전체 의존성 검토가 끝난 것은 아니다. 현재 코드·문서를 라이선스 검토가 완료된 제품으로 표현하지 않는다.

설치·업데이트·복구 지원의 책임, 고객이 수정한 버전의 지원 범위, 실제 배포 파일의 서명·검증·보관 버전을 정한다. 가격·ROI·지원 계약은 미확정이며 이 문서가 대신 결정하지 않는다. 고객의 동의 없는 외부 진단 전송·복제 감시·원격 메시지 기능은 추가하지 않는다.

배포 전에는 [업데이트 절차](maintenance.md), [백업·복구](backup_restore.md), [최신 검증](../development/verification_latest.md)을 확인한다. 이번 문서 작업은 push·PR·저장소 공개 범위·판매 계약을 변경하지 않는다.
