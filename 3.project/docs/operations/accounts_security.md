# 계정·로그인·퇴사 처리

> 상태: 현재 기준
> 확인일: 2026-10-09
> 기준: HEAD `54a8841` + 미커밋 작업 트리. 작업 트리 기준. 설치 검증 범위는 고객 패키지 안내 참조.

| 항목 | 구현된 동작 또는 남은 범위 |
| --- | --- |
| 로그인 | 등록된 이메일과 비밀번호로 로그인. 무작위 salt를 쓰는 PBKDF2 해시 저장, 초기 비밀번호 변경 요구 |
| Caps Lock | 비밀번호 입력 중 Caps Lock 경고. 입력 편의 기능이며 추가 인증은 아님 |
| 반복 실패 | IP·이메일별 5분 안에 8회 시도 시 제한. 단일 서버 메모리 기반이며 재시작 후 유지되는 계정 잠금은 아님 |
| 로그인 유지 | HttpOnly·SameSite 쿠키, 서버의 세션 해시와 만료 확인. 비밀번호 변경 시 기존 세션 모두 폐기 |
| 역할 | 담당자와 대표의 권한을 API에서도 확인 |
| 직원 퇴사 | 대표가 해당 계정을 비활성화하면 모든 기존 세션 폐기·새 로그인 차단. 계약과 감사 이력은 보존 |
| 2차 인증 | 현재 미구현. 판매 전 회사 요구에 따라 인증 앱의 일회용 번호(TOTP) 또는 사내 SSO 연계 검토 |

계정 비활성화로 이미 내려받은 파일까지 회수할 수는 없다. 퇴사 절차에는 사내 PC·공유폴더·백업 접근 권한 회수도 포함한다. 앱 계정 관리와 Windows 자료 폴더 접근 권한은 별도로 관리한다.
