## 0. 5초 첫 화면 보기

화면을 5초 보고 닫은 뒤 두 가지만 말해 주세요.
1. 이 화면에서 **가장 먼저 해야 할 일**은 무엇인가요?
2. 처리할 계약은 몇 건인가요?

## 당신의 역할

당신은 **작은 회사(직원 6명)의 계약 담당자**입니다. 거래처가 보낸 서류를 확인하고, 문제가 있으면 거래처에 다시 요청하고, 대표가 확인할 수 있게 정리합니다.

필수 서류는 6종입니다: 외주용역 계약서 · 견적서 · 사업자등록증 · 통장사본 · 전자세금계산서 · 납품 검수확인서
(계약서와 검수확인서는 회사 안에서 작성하는 서류, 나머지 4종은 거래처에게 받는 서류입니다.)

## 과제 1 — 서류 확인과 요청

진행자가 한 계약의 서류 묶음과 **등록된 계약 정보**(금액·사업자번호)를 줍니다.

**해야 할 것**
1. 서류를 확인해 **문제가 있는지** 찾습니다.
2. 문제가 있으면 **누구에게 무엇을 요청할지** 정하고 요청 문구를 준비합니다.
3. 요청했다고 가정하고 **요청 기록**(연락 방법·기한)을 남깁니다. 앱에서는 요청 문구 창의 **“요청했어요 · 기록하기”**입니다.
4. 대표에게 "이 계약은 아직 끝나지 않았다, 이유는 ○○"를 전달할 수 있게 정리합니다. 앱에서는 요청을 기록하면 계약이 **③ 보완** 단계로 넘어가 이유와 기한이 남습니다.

## 과제 2 — 다시 받은 서류 처리

진행자가 한 계약의 서류 묶음과 등록된 계약 정보를 줍니다.

**해야 할 것**
1. 서류를 확인해 **문제가 있는지** 찾고, 근거가 되는 서류와 금액을 확인합니다.
2. 거래처에 요청하고 요청 기록을 남깁니다(앱: **“요청했어요 · 기록하기”**).
3. 요청이 맞으면 진행자가 **거래처가 고쳐 보낸 서류**를 바로 줍니다.
4. 고쳐 받은 서류를 **이전 서류와 구분해** 반영하고, 문제가 해결됐는지 다시 확인합니다(앱: **“고친 본 올리기”**, 그다음 요청의 **“답 받음”**).
5. 대표가 확인할 수 있게 결과를 정리합니다(앱: 문제가 풀리면 **④ 결재** 단계의 **“대표님께 보낼 문장 복사”**). 대표 결재와 지급 기록은 이 과제에 포함하지 않습니다.

## 방식별 안내

| | 기존 방식 | 앱 |
| --- | --- | --- |
| 쓰는 도구 | 폴더·문서 뷰어·Excel, 업무 기준표 | 시연 업무함(담당자 계정) |
| 요청 문구 | 직접 작성 | 앱이 만든 초안을 검토해서 사용 |
| 요청 기록 | 기록표에 작성 | 요청 문구 창의 “요청했어요 · 기록하기” |
| 고쳐 받은 서류 | 폴더에서 이전본·현재본 구분 | “고친 본 올리기” (이전 서류는 자동 보관) |
| 대표용 정리 | 기록표에 한 줄 | 문제가 남으면 ③ 보완에 이유·기한이 남음 / 풀리면 ④ 결재의 “대표님께 보낼 문장 복사” |

## 규칙

- **시작:** 진행자가 "시작"이라고 말하고 자료를 보여 줄 때부터 잽니다.
- **끝:** "끝났습니다"라고 말하면 멈춥니다. 앱이 서류를 읽는 동안 기다리는 시간도 포함됩니다.
- **10분**이 지나면 멈춥니다. 다 못 해도 괜찮습니다. 그것도 중요한 결과입니다.
- 막히면 **"도움이 필요해요"**라고 말해 주세요. 진행자는 도와준 내용을 기록합니다.
- 진행하면서 떠오르는 생각을 **소리 내어 말해 주면** 큰 도움이 됩니다. ("이 버튼이 뭔지 모르겠다", "이건 왜 빨간색이지")
