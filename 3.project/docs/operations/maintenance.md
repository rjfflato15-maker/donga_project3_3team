# 업데이트와 사내망 유지보수

> 상태: 현재 기준
> 확인일: 2026-10-09
> 기준: HEAD `54a8841` + 미커밋 작업 트리. 작업 트리 기준. 설치 검증 범위는 고객 패키지 안내 참조.

고객 업데이트 절차는 **버전 확인 → 백업 → 서버 종료 → 검증한 앱 파일 교체 → 실행 환경과 DB 변경 확인 → 시작·로그인·문서 조회 확인**으로 정한다. 자료·백업·고객 설정 폴더는 앱 파일 교체 대상에서 제외한다. DB 구조를 바꾼 버전은 전용 이주와 복구 검증을 준비해야 하며, 이전 코드만 되돌리면 DB도 복원된다고 가정하지 않는다. 이번 작업에 자동 업데이트·서명 검증·DB 버전 이주 체계를 구현하지는 않았다.

| 회사 환경 | 가능한 유지보수 경로 | 사전에 필요한 합의 |
| --- | --- | --- |
| 회사가 승인한 원격 접속 가능 | 회사 VPN 등으로 승인된 작업 시간에 지원 | 접속 계정·권한·작업 기록·고객 승인 |
| 외부 접속은 막고 파일 반입 가능 | 검증한 업데이트 묶음과 안내를 전달해 사내 담당자가 적용 | 반입 절차·검증·백업·복구 방법 |
| 외부 접속과 파일 반입이 모두 제한 | 현장 방문 또는 회사 내부 관리자가 승인된 절차로 작업 | 일정·작업 범위·방문 비용 |

변경할 소스와 확인 명령은 [개발자 작업 안내](../development/maintenance.md)를 따른다. 판매 시 지원 범위는 [배포와 판매 검토](distribution.md)를 참고한다.
