# 업무 흐름·백업 복원 연결 점검

**인증된 실제 API 호출 102개 확인 항목 통과**, 관련 회귀 테스트 **78개 통과**.
dev 기반 `team-test-dev-v1`만 사용했다. LLM·가드·프롬프트 실행 0건, 캐시 없음, NTS disabled.
실제 업무함과 test/test2는 사용하지 않았다. 새 서버를 띄우거나 기존 서버를 종료하지 않았다.

## 확인한 연결

| 흐름 | 확인 결과 |
| --- | --- |
| 담당자·대표 로그인 | 실제 로그인·임시 비밀번호 변경 API 사용. 비로그인 조회·ZIP은 401 |
| 누락 → 요청 기록 | 통장사본 누락 1건, 회신 대기 1건·기한이 목록에 반영. 대표 최종 확인은 400으로 차단 |
| 금액 차이 → 보완 요청 → 재발행 | 견적 금액 차이 1건, 수정본 반영 후 차이 0건. 이전본 다운로드 바이트 동일 |
| 원문 근거·칸별 확인 | 견적 금액의 규칙 출처·근거 제공. 합계 한 칸 확인 후 사업자번호 출처는 규칙으로 유지 |
| 맡긴 일 처리 | 자료 변경 후 계약 업무 완료 200. 이전 서류의 업무 완료 409. 업무 완료로 결재가 바뀌지 않음 |
| 회신 처리 | 대기 수·기한 해제, 중복 회신 처리 409 |
| 대표 확인 | 담당자 최종 결재 403, 이전 revision/fingerprint 결재 409, 최신 자료 대표 확인 성공 |
| ZIP 실제 수신·내용 | 가린 본/원본 ZIP을 API에서 수신·저장·압축 검사. 현재본 6개·이전본 1개, 요청·업무·대표 확인 이력 포함 |
| ZIP 원본·가림 | 원본 전체 해시 일치. 가린 JSON의 거래처명·번호 제거. 가림/원본 여부가 감사 이벤트에 남음 |
| 업무 백업·복원 | 대표 백업 API 사용, 새 폴더에 복원. 업무 테이블 10개 내용 해시·파일 36개 해시 모두 일치 |
| 복원 후 실제 사용 | 이전 로그인 쿠키 401, 새 로그인 성공. 누락·회신 대기와 수정·대표 확인 상태 유지, 이전본 포함 ZIP 재다운로드 성공 |

가린 ZIP의 견적서 1쪽을 별도로 렌더링해 공급자·공급받는자 상호/번호 가림, 금액·발행일 보존을 AI가 육안 확인했다. 모든 문서·서식의 개인정보 제거를 보증하는 검사는 아니다.
API를 인프로세스 HTTP 클라이언트로 호출했고 판독·규칙·DB 저장을 모의 응답으로 대체하지 않았다. 브라우저 버튼 클릭, 확인창 취소, 다운로드 폴더 저장, 사내망 접속은 이번 점검 범위 밖이다.
102개는 독립된 계약 102건이 아니라 HTTP 상태·연결된 데이터·권한·파일 확인 항목 수다. 시간 절감 성능은 아직 측정하지 않았다.

## 발견·수정한 오류

견적서·세금계산서의 **공급받는자 정보 아래에 놓인 공통 금액/발행일 블록**을 공급받는자 항목으로 분류해 근거를 누락했다.
`review_context_service.py`의 표시 근거 선택에서 공급자 구분은 상호·사업자번호에 적용하고 금액·날짜는 실제 라벨·값 일치로 위치를 찾도록 수정했다.
복수 근거는 AMBIGUOUS를 유지한다. 실제 판독값·LLM 채택·거부·가드·규칙 판정·정답·평가 수치는 바꾸지 않았다.
새 근거가 현재 화면에 반영되려면 다음 검증용 백엔드 재시작이 필요하다. API 스키마와 frontend 수정은 없다.

## 재현과 기록

```powershell
# 3.project에서, 기존 경로와 겹치지 않는 새 이름 사용
backend/.venv/Scripts/python.exe backend/scripts/rehearse_team_workflow.py --output storage/demo/team-test/flow-run-new
```

도구는 새 시연 업무함 생성 → API 흐름 → 대표 백업 → 새 폴더 복원 → 복원 서버의 API 재확인을 순서대로 실행한다.
검증용 로그인 정보·쿠키·백업·다운로드 ZIP은 Git에서 제외된 해당 시연 폴더에만 저장한다. 기존 업무함을 덮어쓰지 않는다.
Windows 이벤트 루프 내부 socketpair만 허용하고 외부 연결과 직접 localhost 연결은 실행 경계에서 차단한다. 모델·가드 금지는 API 작업 스레드에도 적용한다.

- 완료 실행: `storage/demo/team-test/flow-run-03/`
- 공개 가능한 결과: [연결 점검 JSON](workflow_rehearsal_result.json). 비밀번호·쿠키·DB 행 원문 없음.
- 기준 main: `81af2b6` + 이번 원문 근거 표시 수정. 이 커밋은 최종 측정 빌드 확정을 뜻하지 않는다.
- 회귀 테스트: review workflow 17, document versions/contract export/backup/assignments/team materials 45, evidence geometry/field confirmation/execution boundary 16.
- 초기 도구 실행의 Windows 내부 socketpair 차단과 발견된 근거 누락은 실패 기록으로 로컬에 보존했다. 수정 후 새 폴더에서 전체 연결을 다시 실행했다.
