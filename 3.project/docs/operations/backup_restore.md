# 백업과 새 폴더 복원

> 상태: 현재 기준
> 확인일: 2026-10-09
> 기준: HEAD `54a8841` + 미커밋 작업 트리. 작업 트리 기준. 설치 검증 범위는 고객 패키지 안내 참조.

관리 메뉴 6번은 실행 중에도 기존 백업 도구의 DB 스냅샷과 원문 자료를 ZIP으로 생성한다. 백업에는 초기 계정 비밀번호 안내 파일을 포함하지 않는다. ZIP 자체는 암호화하지 않으므로 회사가 정한 암호화 저장소와 접근 권한, 보관 기간을 적용한다.

7번 복원은 서버가 종료되어 있고 아직 존재하지 않는 새 폴더에서만 진행한다. 기존 복원 도구가 파일 경로와 해시를 확인한다. 복원에 성공한 다음 실행 설정의 자료 폴더를 바꾸며, 실패하면 현재 설정은 유지한다. 복원된 DB의 로그인 세션은 모두 만료되어 다시 로그인해야 한다. 이전 업무함은 자동 삭제하지 않는다.

## 자동 실행과 일일 백업

8번 예약 작업은 사용자가 직접 등록할 때만 생성된다. 자동 실행은 **현재 Windows 사용자가 로그인한 뒤** 시작한다. 자동 백업 기본 시각은 18:00이다. 로그인 전 부팅 서비스, 서버 장애 후 상시 재시작 감시, PC가 꺼져 있을 때 백업, 자동 실패 알림까지 구현한 것은 아니다. 해제는 Windows 작업 스케줄러의 `C-Pilot-Contract-App`, `C-Pilot-Daily-Backup`에서 비활성화하거나 삭제한다.
