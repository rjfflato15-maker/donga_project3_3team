# 사내망과 다른 PC에서 접속

같은 회사에서 사용할 때는 자료를 PC마다 복제하기보다 서버 PC 한 대를 유지하고 직원 PC는 브라우저로 접속하는 구조다. 실행 설정의 사내망 허용을 켜고 `http://서버의사내IP:포트/`로 접속한다. 서로 다른 직원은 개인 계정을 사용한다. 다른 브라우저와 PC의 로그인 세션은 각각 생성되며 계정 비활성화·비밀번호 변경은 해당 계정의 세션 전체에 적용한다.

통합 실행기는 기본적으로 로컬 HTTP이고, 사내망 옵션은 바인딩 주소를 바꾸는 기능이다. HTTPS·인증서·방화벽·VPN을 자동 구성하지 않는다. 실제 회사의 로그인·문서 통신을 보호하려면 IT 담당자가 HTTPS와 회사 대역 접근 제한을 준비한다. HTTPS 역방향 프록시 운영은 별도 설정으로 `APP_COOKIE_SECURE=true`와 접속 주소를 적용한다. 현재 간편 실행기는 HTTP용 쿠키 설정을 사용하므로 그 상태로 HTTPS 운영 완료라고 설명하지 않는다.

서버 PC를 교체할 때는 기존 서버를 종료하고 백업한 뒤 새 PC의 실행 환경을 준비한다. 백업을 새 자료 폴더에 복원하고 접속 주소를 변경한다. SQLite DB 파일을 여러 PC에서 네트워크 공유로 동시에 직접 여는 방식은 지원 경로가 아니다.
