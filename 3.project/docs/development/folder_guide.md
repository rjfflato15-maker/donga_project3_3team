# 폴더를 보관하고 정리하는 기준

탐색기에서 평소 사용할 것은 프로젝트 루트의 **C-Pilot.exe**다. 첫 준비는 **start_pilot.bat**, 안내는 **README.md**다. 개발·운영용 실행 파일은 `tools/`로 묶었다.

| 구분 | 경로 | 보관·삭제 기준 |
| --- | --- | --- |
| 앱 소스 | `backend/`, `frontend/` | 실행·개발에 필요. 유지 |
| 도구 | `tools/` | 개발·백업·배포에 사용. 일반 사용자는 직접 실행할 필요 없음 |
| 운영 자료 | `storage/` | DB·원본·로그·설정. 임의 삭제 금지 |
| 문서 | `docs/` | 실행 안내와 개발 근거. [목록](../README.md)에서 필요한 것만 읽기 |
| 개발 평가 | `eval/`, `docs/eval/dev/` | 정답·사람 출처·비교 근거. 현재 평가가 끝날 때까지 보존 |
| 검수 Excel | `outputs/` | 확정 정답 출처와 연결된 원본·사본. 현 위치 보존 |
| 개발 샘플 | `sample-data/` | 기존 개발·데모 참조. 현재 참조가 있어 유지 |
| 재생성 캐시 | `.pytest_cache/`, `__pycache__/` | 다시 만들 수 있어 삭제 가능. pytest 캐시는 작업 공간의 `tmp/pytest_cache/` 사용 |
| 로컬 임시 작업 | 작업 공간의 `tmp/` | 프롬프트와 진행 중 자료 포함. 필요 여부 확인 후 정리, Git 제외 |
| 예전 산출물·수동 백업 | 작업 공간의 `_local_archive/` | 기존 output과 rollback 백업을 보존, Git 제외 |

`_local_archive/move_receipt.json`에는 이동 전후 보관 파일의 상대 경로와 SHA256을 기록했다. 사용자 문서와 백업은 삭제하지 않았으며 이 기록도 로컬 보관용이다. 사용자가 삭제한 작업 공간의 `자료/`는 복원하지 않았다.

개발용 전체 프로젝트와 고객용 배포는 같은 구성이 아니다. 고객용으로 제공할 파일은 [배포 경계](distribution_boundary.md)를 보고 별도로 고른다. 자료·캐시를 정리하면서 정답 파일·문서 해시·평가 경로를 임의로 바꾸지 않는다.
