# 시범 C안 이후 작업 현황

계약 증빙 검수 앱에 로컬 AI 보완과 근거 검증을 추가하고, 정확도를 측정할 수 있게 정리했습니다. 아래는 로컬 커밋까지 완료한 내용입니다. 원격 업로드는 아직 진행하지 않았습니다.

## 완료한 내용

| 항목 | 달라진 점 |
| --- | --- |
| 앱 안정성 | OCR·미리보기 등 무거운 작업 중 다른 요청이 막히는 문제를 보완하고 동시 처리 확인을 추가했습니다. 실패한 파일·페이지 요청에 성공 응답 준비 감사 기록이 남는 문제도 수정했습니다. |
| 문서 AI | 기존 규칙 추출에 Ollama의 로컬 qwen3 보완을 추가했습니다. 규칙이 값을 못 찾거나 모순이 있는 필드에만 호출하며, 최종 PASS/FAIL 판단은 규칙이 합니다. 외부 AI API를 추가하지 않았습니다. |
| 근거 검증 | AI가 제안한 값의 원문·위치·라벨·공급자 구역·모호함·형식·계산을 확인합니다. 근거가 부족하면 사람 확인으로 넘기고 사유를 저장합니다. DOCX는 물리 페이지 대신 문단·표 위치를 확인합니다. |
| 평가 체계 | 합성 서류를 개발용과 최종 평가용으로 분리하고, 정답표와 자동 측정 도구를 만들었습니다. 사람이 원문으로 113칸을 확인했고 나머지 781칸은 두 AI 초안 일치로 검증했습니다. 사람 전수 검수는 아닙니다. |
| 실행과 운영 | 평소 C-Pilot.exe 하나로 실행하고, 관리 메뉴에서 준비·설정·백업·복원 등을 처리하도록 묶었습니다. 처음에는 start_pilot.bat으로 EXE를 생성합니다. EXE와 앱 폴더·실행 환경은 함께 필요합니다. |
| 보안·계정 운영 | 비밀번호 해시 저장, 반복 로그인 시도 제한, 역할별 권한, 계정 비활성화 시 모든 세션 폐기 동작을 확인하고 운영 지침을 정리했습니다. Caps Lock 안내는 입력 편의 기능이며 2차 인증은 아직 없습니다. 다른 PC는 서버 한 대에 개인 계정으로 접속하는 방식을 안내했습니다. |
| 유지보수 | 실행·운영·개발·Docker 도구와 문서를 역할별로 분리했습니다. 중복 파일을 줄이고 옛 산출물·백업은 별도 로컬 보관함에 보존했습니다. 프로젝트 첫 화면 항목은 28개에서 15개로 줄었습니다. |

## 개발용 성능 결과

같은 확정 dev 정답의 핵심 필드 337칸을 측정했습니다. 가드 유무 비교에는 같은 LLM 응답을 재사용했습니다.

| 조건 | 핵심 필드 정확도 |
| --- | ---: |
| 규칙만 | 78.34% |
| LLM만 | 94.66% |
| 규칙 + LLM, 가드 없음 | 99.11% |
| 규칙 + LLM, 가드 v3 있음 | 98.52% |

가드는 **답이 맞더라도 근거가 부족하면 자동 채택을 보류**하므로, 가드 없는 방식보다 정확도 점수가 조금 낮습니다. 그 대신 출처를 확인하고 근거가 부족한 값을 담당자에게 넘깁니다. 가드 조정 전 거부했던 오답 두 건은 계속 차단하면서 맞는 값의 불필요한 거부를 줄였습니다. 원문 OCR 자체의 오독은 남아 있으며, 모든 오류를 해결한 것은 아닙니다. 이번 dev에서 잘못된 PASS는 네 조건 모두 0/17건이므로 가드가 잘못된 PASS를 줄였다는 결론은 낼 수 없습니다.

가드 v3는 dev 감사 결과로 조정한 버전입니다. 이 수치는 최종 test 성능이 아닙니다. 가드가 채택한 제안값은 68/69개가 정답과 일치했고, 보완 요청 80필드 중 11개는 추가 사람 확인으로 넘겼습니다.

## 앞으로 할 일

- test 정답 확인·확정 후, 고정한 버전으로 최종 평가를 한 번 실행합니다. test 문서·정답은 아직 열지 않았습니다.
- 근거와 거부 사유를 보여 주는 화면은 시안 승인 후 구현합니다. 일반 앱의 LLM 보완은 현재 기본 비활성입니다.
- 제출 문서와 데모를 준비하고, 여유가 있으면 결과 요약과 검수 에이전트를 추가합니다.
- 2차 인증, HTTPS 운영 구성, 앱 전체를 포함한 판매용 설치 패키지와 자동 업데이트는 별도 범위입니다.

현재 확인된 전체 회귀 검증은 백엔드 209개 테스트와 프런트 빌드 통과입니다. 기존 경고는 남아 있습니다. 이번에는 승인한 서류·체크 아이콘을 EXE에 추가했으며 앱 화면은 변경하지 않았습니다.
