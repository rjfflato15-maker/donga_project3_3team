## 현재 앱과 배포 범위

기준은 구조 정리가 반영된 현재 소스 사본이다. 실제 화면·공통 모듈·API·회귀 테스트는 [소스 책임 지도](../architecture/module_map.md)에서 연결한다. 이번 배포는 소스 전용이며 과거 HEAD나 이전 Setup을 현재 소스의 검증 결과로 사용하지 않는다.

## 검증과 평가

최신 회귀·빌드·문서 확인 결과는 [검증 기록](../development/verification_latest.md)에서 관리한다. 자동 테스트 통과와 실제 모델/화면 확인, 고객 설치 검증을 구분한다.

2026-10-09 수정본을 노트북에 반영하고 Windows 백엔드 전체 902개를 검증했다. 이후 실행 서버·원문 확인 이동·조회 성능을 수정하고 백엔드 전체 912개와 프런트엔드 전체 35파일 168개·배포 빌드를 검증했다. 전체 902개는 성능 수정 전 기록이다. 목록에서 전체 PDF를 다시 추출하지 않고, 원문 대조에서 선택 서류의 위치만 불러오며 해시 검증 후 제한된 메모리 캐시를 재사용한다. 가상 한국어 이미지 OCR 단위 테스트는 통과했으며 실제 고객 문서 정확도·실시간 모델·현재 소스의 Setup 재빌드는 별도다. 8000번 서버를 같은 데이터·설정으로 재시작했고, 가상 복사본에서 원문 확인 저장·다른 항목 이동·처리 기록 조회를 실제 브라우저로 확인했다. 전체 화면·업무 흐름 전수 검증이나 다중 사용자 부하 시험을 뜻하지 않는다. 기존 평가 자료 1,258개는 변경하지 않았다.

10월 7일 이전 검증 숫자는 당시 기록이며 현재 버전의 통과 수로 재사용하지 않는다. 최신 결과는 위 검증 기록에서 범위와 날짜를 함께 확인한다. 서버와 고객 자료를 분리한 UI 검증 및 실제 모델 시험의 구분은 [디자인 검증 기록](../../design-qa.md)을 따른다. Windows 백엔드 검증에는 Python `-X utf8`과 쓰기 가능한 임시 경로를 사용한다.

기존 가드 v3 test와 v4 test2는 자료·버전·분모가 다르다. 현재 앱의 모든 신규 기능을 기존 평가가 검증했다고 표현하지 않는다. [평가 요약](../submission/evaluation_results.md)에서 네 조건과 제한을 확인한다. 실제 사용자 작업시간 절감과 월 업무량 처리 성능은 실측 전이다.
