# 승인한 실행 파일 아이콘 적용

사용자에게 세 가지 이미지 시안을 제시하고, 서류와 체크 표시를 결합한 1번 시안의 적용 승인을 받았다. 앱 화면의 디자인 변경 없이 Windows 실행 파일 아이콘만 적용했다.

선택한 PNG를 `tools/launcher/assets/cpilot.png`에 보존하고 Windows용 `cpilot.ico`로 변환했다. ICO에는 16·24·32·48·64·128·256픽셀 크기를 포함했다. 빌드 스크립트에 `/win32icon` 옵션을 추가하고, C# 소스뿐 아니라 아이콘과 빌드 스크립트가 변경되어도 초기 BAT 실행 시 다시 빌드하도록 수정했다.

별도 임시 폴더에서 같은 빌드 스크립트를 실행하여 컴파일, 변경 없는 경우의 재빌드 생략, 아이콘 변경 시 재빌드를 확인했다. Windows API로 EXE의 내장 아이콘을 추출하고, 실제 `C-Pilot.exe`에 적용한 뒤 동일한 아이콘인지 픽셀을 대조했다. EXE의 상태 명령으로 기존 서버와 실행 환경이 준비된 상태임을 확인했다. 사용자 서버를 종료하거나 로그인 상태를 변경하지 않았다. 재생성 가능한 EXE는 계속 Git에서 제외하고 원본 이미지·ICO·빌드 소스만 관리한다.

추출·검수 코드와 평가 정답을 변경하지 않았고 test 자료는 열지 않았다. 이번 확인은 아이콘·빌드·기존 상태 명령에 한정했다. 이전 전체 백엔드 209개 테스트와 프런트 빌드 결과는 [폴더 정리 기록](12_folder_cleanup.md)에 있다. 공유용 핵심 요약은 [팀 공유 문안](../team_update.md)에 저장했다.
