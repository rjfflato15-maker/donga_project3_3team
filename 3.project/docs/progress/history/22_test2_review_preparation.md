# test2 독립 판독과 사람 확인 준비

이 문서는 준비 당시의 기록이다. 이후 실제 응답·사람 확인·고정 예측·확정 결과는 [연휴 고도화와 test2 완료](23_holiday_backend_and_test2.md)에 기록했다.

사용자의 test2 준비 요청에 따라 기존 hard-v2 계약 6건·PDF 36개를 재사용했다. 원문과 정답 초안은 다시 만들거나 수정하지 않았다. 기존 dev/test 확인표와 사람 결과도 변경하지 않았다.

가드 v4·프롬프트 v3·qwen3 모델 digest·설정·평가 관련 코드 해시를 먼저 고정했다. 그 뒤 원문 미리보기 2개를 검수 화면의 크기와 잘림 확인 목적으로만 확인했다. test2로 튜닝하거나 OCR·LLM 추론·가드·최종 채점을 실행하지 않았다.

독립 판독 묶음은 50개 파일 및 ZIP의 바이트 해시를 확인했다. 프롬프트의 로컬 경로를 test2 전용으로 수정하고 case_01~06의 실제 응답 6개를 한 번에 저장하도록 안내했다. 현재 replies는 0개이며 사람 확인 페이지는 판독 대기 상태다. 독립 답을 대신 만들거나 빈 페이지를 검수 준비 완료로 표시하지 않았다.

`backend/scripts/prepare_test2_review.py`는 고정·묶음 확인, 실제 응답 대조, 기존 빌더로 확인표·페이지 생성, 사람 결과의 sheet+row+ID+양식 해시 검증과 사본 반영을 연결한다. 기존 절차대로 불일치·해석·모호함과 일치 10% 표본만 사람 확인 목록으로 선정한다. 정확한 검수 칸 수는 Claude 응답 수령 뒤 정해진다.

고정 이후 변경·ZIP 변조·미응답·예전 사람 결과 재사용을 막는 테스트와 기존 평가 테스트 48개가 통과했다. frontend와 실제 업무함은 변경하지 않았다. 이번 작업에는 병행 세션의 API·업로드 작업을 포함하지 않는다.
