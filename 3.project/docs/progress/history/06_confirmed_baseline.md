# 사람 확인과 확정 규칙 기준 성능 작업 기록

이 문서는 해당 작업 당시의 기록이다. 현재 상태는 [진행 요약](../development_report.md)을 확인한다.

## 사람 검수 완료와 정식 규칙 기준 성능

2026년 10월 2일 검수자 이창헌이 `eval/human_review_page`에서 원문을 보며 113칸을 확인한 결과 JSON을 전달했다. 113칸 모두 확인이며 수정과 보류는 0건이다. 원본 JSON을 `eval/human_reviews/human_review_result_이창헌.json`에 바이트 그대로 보관하고 SHA256 출처 기록을 남겼다. 칸별 확인 시각과 근거도 보존했다. 확인 시각은 같은 날 10:08~10:21 KST이다. 사용자의 직접 검수 기록이며 Codex가 사람을 대신해 확인 표시를 만든 것이 아니다.

원본 `human_review.xlsx`는 보존하고 사본 `human_reviewed.xlsx`의 K·L열에 시트명·행 번호·확인 ID를 일치시켜 반영했다. B12에는 검수자 이창헌을 기록했다. 가져오기 절차로 `ground_truth_dev.json`을 확정하고 정답·Excel·자료 목록·사람 결과 JSON의 해시 및 칸별 확인 시각 출처를 남겼다. 생성 정보 초안과 Claude 응답은 변경하지 않았다.

113칸(해석 26칸 + 일치 항목 10% 표본)은 사람이 원문을 보고 확인했고, 나머지 781칸은 두 AI 초안의 일치로 검증했다. 사람 전수 검수라고 기록하지 않는다. 확인 대상이 아닌 DOCX 모든 페이지의 시각 검증까지 완료했다고 주장하지 않는다.

확정 정답 기준의 규칙 성능은 분류 Macro F1 1.0000, 핵심 필드 정확도 78.34%(264/337), 누락 Recall 1.0000(2/2), 교차검증 Macro F1 0.7530, 문제가 있는 항목에서 잘못된 PASS 0/17이다. FAIL 정답 4건 중 FAIL 검출은 1건이다. 수정 없이 확정되어 초기 예비 수치와 같지만, 이제 확정 정답 기준의 dev 개발 평가다. 별도 test 결과나 실제 회사 서류 성능으로 해석하지 않는다. 결과는 `docs/eval/dev/baseline/`의 JSON·Markdown·CSV에 저장했다.

dev 측정과 정답 가져오기에서는 test 파일 내용을 열지 않도록 자료 해시 확인 범위를 dev로 제한했다. dev/test 서식 분리 여부 등 목록 메타데이터 검사는 유지한다. 최종 `--final` 전에는 test 문서와 정답을 개발·튜닝에 사용하지 않는다.
