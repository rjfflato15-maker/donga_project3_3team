| 확인 범위 | 칸 수 |
| --- | ---: |
| 해석 확인 | 46 |
| 모호한 값 | 3 |
| 나머지 일치 항목의 10% 표본 | 85 |
| 사람이 원문을 보고 직접 확인 | **134** |
| 두 AI 초안의 일치로 검증 | **760** |
| 전체 정답 항목 | 894 |

`eval/human_reviews/test/human_reviewed.xlsx` 사본의 K·L열에 실제 확인과 근거를 옮기고 안내 B12에 이창헌을 기록했다. 원본 확인표와 사람 확인 페이지는 변경하지 않았다. 사본은 B12·K·L열 외 값과 서식이 원본과 같음을 확인했다. 원본 결과 JSON은 같은 폴더에 바이트 그대로 보관했다.

기존 가져오기 절차로 `eval/dataset/ground_truth_test.json`을 확정하고 `.freeze.json`에 정답·원문 목록·확인표·원본 결과·독립 판독·대조 기록 해시와 사람 확인 범위를 남겼다. 정답 내용은 두 초안과 같고 사람 확인 출처가 추가됐다. 사람 전수 검수로 기록하지 않았다.

원본 결과 JSON SHA256: `5a90e6dc72915946db2b7e15dc7e496cbb437a0820a592a5f9a5092a4779059d`.

고도화 세션의 합의에 따라 v3 test 예측은 정답과 별도로 한 번 보존하는 절차가 진행 중이다. 이 작업은 새 모델 호출이나 가드 재실행을 시작하지 않았다. 고정 예측이 완성되면 확정 정답으로 채점하고 결과를 별도 기록한다.
