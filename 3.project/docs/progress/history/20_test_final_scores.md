# 고정 v3 test 확정 채점

합성 test 10계약·59문서의 고정 예측 패키지 해시를 검증하고, 이창헌의 실제 원문 확인 결과로 확정한 정답을 사용해 채점했다. 예측 시도는 `e40c42cf-cc17-4939-8f11-d8df9452f954` 한 번이다. 이 세션의 채점에서 추가 추론·가드 재실행은 0회이며 v3 모델·프롬프트·가드와 test를 변경하거나 튜닝하지 않았다.

| 조건 | 핵심 필드 정확도 | 검수 상태 정확도 | 잘못된 PASS |
| --- | ---: | ---: | ---: |
| 규칙만 | 75.67% | 81.71% | 0 |
| LLM 필드 추출만 | 83.09% | 95.95% | 0 |
| 규칙+LLM, 가드 없음 | 94.66% | 97.33% | 0 |
| 규칙+LLM, 가드 있음 | 77.74% | 81.71% | 0 |

LLM 보완은 가드가 없을 때 규칙만보다 18.99%p 개선됐다. 가드 적용은 미적용보다 16.91%p 낮았으며 필드 정확도 목표 90%를 달성하지 못했다. dev 가드 적용의 98.52%와 구분해야 한다.

가드는 111개 제안을 거부했고, 그중 정답과 일치한 제안이 100개·불일치한 제안이 11개다. 주된 거부 사유는 FIELD_LABEL_OR_VALUE_MISMATCH 107건이다. 한 제안에 여러 거부 사유가 있을 수 있다. 맞는 값을 막는 문제가 새 test 서식에서 커졌지만 이 결과로 v3를 조정하거나 같은 test를 다시 추론하지 않았다.

채택한 VALUE는 10개 모두 정답과 같았다. 이는 10건의 100%이며 전체 채택 정확도나 상용 성능을 뜻하지 않는다. 채택 비VALUE 제안 중 정답 불일치도 9건 있다. 보완 요청 필드 130개 중 111개(85.38%)는 추가 사람 확인으로 넘어가고 기계 근거 검증 완료율은 14.62%다. 전체 문서 기준 추가 확인은 24/59개(40.68%)다. 최종 담당자 승인은 별도 단계다.

잘못된 PASS는 네 조건 모두 0개로, 이번 test에서 가드의 안전성 우월성을 입증하지 못했다. 거부값은 추가 확인 대상으로 기록했으며 전부 오답으로 세지 않았다. 기존 dev 수치는 보존했다. v4 개선과 평가는 별도 dev2·test2에서 진행하고 v3 test 실패 사례로 튜닝하지 않는다.

[전체 결과·정의](../../eval/test/final/four_modes.md), 같은 폴더의 JSON·CSV·가드 사후 대조를 보관했다. 모델 응답과 원문은 고정 예측 패키지, 정답의 검수 범위와 해시는 확정 정답 기록에 보존했다. 사람 전수 검수나 실제 업무시간 절감을 주장하지 않는다.
