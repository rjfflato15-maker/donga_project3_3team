# test 독립 판독 대조와 사람 확인 준비

Claude 실제 응답 10개를 대조했다. 원본 묶음의 81개 수령 해시가 일치하고 59문서 모두 판독 완료다. 평가 정답 초안과 **894칸 모두 일치, 불일치 0·미응답 0**이다. 일치만으로 사람 검수 완료나 성능을 주장하지 않는다.

사람 확인 목록은 **134칸: 해석 46 + 모호함 3 + 일치 표본 85**다. 필수 49칸을 제외한 일치 845칸에서 10%를 올림해 사례·문서 종류별로 뽑았다(seed 42). dev 확정 기준을 유지하고 새 해석 질문 다섯 주제도 포함했다. 정답 초안·독립 판독 원본은 수정하지 않고 질문 v2와 대조 결과에 선정 이유·입력 해시를 저장했다.

기존 빌더로 쉬운 문장·기준·잘라낸 원문을 제공한다. 누락/불일치를 반대로 쓰던 문구, 적용 대상 아닌 검사를 적용한다고 읽히던 문구, dev 금액을 고정한 산술 힌트를 수정했다. 국세청 미연동은 REVIEW, 참고 금액은 REVIEW, 검수확인서 전체 금액은 FULL, 명시한 전액 청구의 합계 오류는 FAIL이라는 기준은 그대로다. 문구 보완은 판정·평가 구현 변경이 아니다.

확인 표의 K·L열과 검수자 B12는 비어 있다. 페이지의 sheet·row·ID·Excel 해시가 일치하고 사람 완료는 0칸이다. 스프레드시트 세 탭을 렌더링해 확인했고 사업자번호는 선행 0이 보이는 문자열로 표시했다. 임시 Playwright 컨텍스트에서 노트북 화면 1366×768·1440×900, 큰 원문·질문·기준, 다음 문항 이동과 콘솔 오류 0건을 확인했다. Browser 플러그인이 없어 번들 Playwright를 사용했고 자동 확인 답을 사람 결과로 저장하지 않았다.

관련 단위 테스트 49개 통과. 최종 정답·평가 실행은 사용자의 실제 원문 확인 결과 JSON을 받은 뒤 수행한다. 준비된 Excel·페이지는 그때까지 수정하지 않는다. 고정 버전 qwen3·프롬프트 v3·가드 v3와 dev 정답·원본은 유지한다.
