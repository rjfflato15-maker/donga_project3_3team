# 초기 가드 평가 기록

이 폴더는 OCR의 `라벨. 값` 구분자를 처리하기 전 평가를 보존한다. 핵심 필드 정확도는 규칙 78.34%, LLM만 94.66%, 규칙+LLM 가드 없음 97.03%, 가드 있음 79.53%였다. 가드 거부 121건 중 FIELD_LABEL_OR_VALUE_MISMATCH가 117건이었다. 이 수치를 숨기거나 최종 결과로 덮어쓰지 않았다.

후속 가드는 점 뒤 공백이 있는 구분자만 해석하며 원문·모델 제안값을 바꾸지 않는다. 소수점 앞에 공백이 없는 `.5`는 구분자로 처리하지 않는다. 이 변경은 실패·모순 필드 선정에도 영향을 주므로 초기 평가와 후속 평가의 차이를 순수한 가드 효과라고 주장하지 않는다. 순수 가드 적용 비교는 각 실행의 ③과 ④가 동일 응답을 사용한 결과로 판단한다.

현재 결과는 상위 폴더의 four_modes 파일이다. 실제 test 자료를 개발에 사용하지 않았다.
