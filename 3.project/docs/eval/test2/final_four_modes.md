# 고정 v4 test2 최종 평가

2026-10-03에 계약 6건·PDF 36개의 예측을 한 번 실행해 보존한 뒤 확정 정답으로 채점했다. 추론은 정답 값을 읽지 않았다. 사람 직접 확인은 81항목이며 나머지 459항목은 두 AI 초안 일치로 채택했다. 사람 전수 검수가 아니다. 독립 판독·사람 확인 이전에 고정한 qwen3:latest·프롬프트 v3·가드 v4와 판정 코드를 사용했고, test2를 보고 모델·프롬프트·가드를 바꾸거나 다시 실행하지 않았다.

LLM 호출 실패는 0건이다. 처리 시간은 저장한 인식·추출·모델 호출 및 해당 조건의 가드 시간으로 계산한 기계 처리 시간이다. 사람 작업 시간·대기 포함 업무 시간·시간 절감 수치가 아니며 서버 대기·웹 요청·모델 준비·전체 평가 실행 시간을 대표하지 않는다. 가드 적용 전후 비교는 같은 hybrid 응답을 사용했다.

## 해석과 제한

규칙+LLM은 규칙만보다 필드 정답 12칸, 5.88%p 많았다. 가드 v4 적용은 규칙만보다 정답 8칸, 3.92%p 많았지만 가드 없는 조건보다 4칸, 1.96%p 낮았다. 가드는 VALUE 제안 18개 중 8개를 채택했고 채택 값은 8/8 정답이었다. 나머지 10개 중 정답과 일치하는 VALUE 제안도 9개 거절했다. 추가로 채택한 ABSENT 2개와 REVIEW 2개는 정답과 일치하지 않았다. 채택 VALUE의 정밀도와 전체 상태·필드의 정확도를 구분해야 한다. 보완 대상 22칸 중 12칸은 미해결·사람 확인 대상으로 남았다.

사용자가 지적한 `404/40402/total_amount`는 합계금액 라벨이 있지만 숫자가 도장으로 가려 읽을 수 없는 항목이다. 정답은 REVIEW/null이며 규칙과 가드 v4는 이를 맞췄고, LLM만과 가드 없는 조건은 VALUE를 내놓았다. 이 사례는 원문에서 읽을 수 없는 값에 숫자를 채워 넣지 않는 가드의 효과를 보여 준다. 다만 모호한 필드는 이 세트에서 1개이고, 잘못된 PASS는 모든 조건에서 0/7이므로 가드의 일반적 안전성 우월성이나 모든 모호한 원문에 대한 효과는 입증하지 못했다.

합성 자료 6계약이며 계약 안의 서류·필드는 서로 관련되어 있다. FAIL·MISSING 정답과 누락 서류 사례는 없어 해당 조건의 검출 성능은 측정하지 못했다. 사람 표본 확인 밖의 AI 일치 항목에도 정답 오류 가능성이 남는다. dev2는 사람 확인 전 예비 수치이고 기존 v3 test는 자료·버전이 다르다. 기존 test의 77.74%와 이번 95.59%를 동일 시험에서의 성능 향상으로 표현하지 않는다. test2의 오류는 이 고정 결과의 제한으로 남기며, 추가 개선은 새 개발 자료로 평가한다.

[질문 범위 추가 점검](../../../eval/reconciliation-test2-v1/question_wording_scope_audit.json)에서 81개 중 N/A 18문항은 N/A 상태 자체 대신 파일 열림·글자 가독성·계산 일치 등 원문 사실을 물었던 것으로 확인했다. 81개는 사람이 읽고 답한 원문 확인 건수이며, 81개의 상태·값 라벨을 모두 직접 확정했다는 뜻으로 쓰지 않는다. 직접 라벨을 묻는 문항은 63개이고 나머지 18개의 N/A 상태 근거는 기존 설계 명세와 독립 판독의 일치다. 제출 페이지 79문항에는 “설명대로면/기준대로면 맞아요”라는 유도 문구도 있어 확인 편향의 가능성을 남긴다. 원본 답·현재 정답 값·점수는 변경하지 않았으며 새 질문 빌더는 이 문구를 제거하고 N/A와 긍정적인 원문 사실/PASS를 구분한다. 이 점검은 사람에게 없는 답을 대신 만들거나 잘못된 클릭으로 처리하는 절차가 아니다.
