# 팀원 테스트 자료 — team-test-dev-v1

진행자는 [준비·초기화 안내](../../docs/operations/team_test_materials.md)를 먼저 읽는다.

| 폴더·파일 | 전달 대상 |
| --- | --- |
| `participant_guide.md` | 참가자 공통 안내. UI 브랜치 안내에서 진행자 전용 부분만 제외한 사본 |
| `packages/practice.zip` | 설명·연습 때만 제공 |
| `packages/task_1_A.zip`, `task_1_B.zip` | 과제 1 — 서류 확인과 요청. 배정된 한 묶음만 제공 |
| `packages/task_2_A.zip`, `task_2_B.zip` | 과제 2 — 다시 받은 서류 처리. 배정된 한 묶음만 제공 |
| `participants/` | 위 ZIP과 동일한 풀린 파일. 원문·계약 정보표·기준표·빈 기록표 |
| `facilitator/` | 진행자 전용 정답, 수정 견적서, 출처·해시. 참가자에게 전달하지 않음 |

**이 폴더 전체를 참가자에게 보내지 않는다.** 순서가 올 때 해당 ZIP 하나만 제공한다.
ZIP에는 정답·앱 검사 결과·수정 견적서가 없다. `originals/`의 PDF만 앱에 업로드한다.
계약 정보표 PDF/JSON은 비교 기준이며 업로드할 증빙이 아니다.
앱 방식에도 같은 ZIP을 제공한다. 기존 방식은 작업용 사본에서 기록·이전본 구분을 한다.
원본 배포 묶음은 그대로 보존한다. 기록표는 Excel에서 열 수 있는 UTF-8 CSV다.

기본 서식은 dev의 단순 문단 배치이며 업체·금액만 새 가상 값으로 만들었다.
정확도 평가용 test/test2 또는 실제 업무 자료는 사용하지 않았다. 시간 측정 결과는 아직 없다.
