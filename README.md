> 확인일: 2026-10-07
> 기준: 현재 앱은 `3.project`. 문서 정리 중이며 설치 패키지 작업은 중단 상태.

| 찾는 것 | 위치와 시작 |
| --- | --- |
| 현재 앱·코드·문서 | [3.project 시작](3.project/README.md) · [문서 포털](3.project/docs/README.md) |
| 초보 개발자 유지보수 | [개발 시작](3.project/docs/development/getting_started.md) · [작업표](3.project/docs/development/maintenance_cheat_sheet.md) |
| 바깥 폴더의 분류·보관 | [작업 공간 경계](3.project/docs/development/workspace_layout.md) |
| 시범 C안 공유본 | `팀공유_시범C안/`은 풀림본, 같은 이름 ZIP은 전달본 |
| 임시 분석·검증·문서 산출물 | `tmp/`. 진행 상태와 재현 필요를 확인한 뒤 정리 |
| 이전 산출물·수동 백업 | `_local_archive/`. 기존 receipt와 복구 근거 보존 |

Git 저장소는 이 작업 공간의 .git이며 앱 소스는 3.project에서 관리한다. 공유 HTML/ZIP을 현재 앱 소스나 최신 완료 상태로 해석하지 않는다. 새 기능의 미커밋 파일은 HEAD만 받아서는 포함되지 않을 수 있다.

이번 정리는 탐색 안내와 문서 기준을 만들며 바깥 폴더·ZIP·백업은 이동하거나 삭제하지 않았다. 고객 자료·초기 계정·환경 설정을 공용 ZIP이나 저장소에 넣지 않는다.
